# What counts as interesting continuity
Continuity = an event in the current session that a player who remembers an earlier session would recognise as connected to it.

## Kinds of connection (draft)

| kind | example | interesting? |
|---|---|---|
| **Relationship change** | Friends from session 1 fight in session 2; a rivalry turns into friendship | high |
| **Returning threat** | The faction that raided in session 1 raids again | high |
| **Consequence** | A colonist injured in session 1 recovers, relapses or dies in session 2; a project started in session 1 is finished | high |
| **Character arc** | A colonist who broke down in session 1 breaks down again, or copes better | high |
| **Recurring presence** | The same animal or pet is still around | low |
| **Routine repetition** | The same kind of job again (hauling to the same stockpile) | low |

## Questions to settle

- Should low-interest kinds count as continuity in the gold at all, or be marked separately (e.g. `weak`)? We should conunt as continuity but mark it as weak/medium/high.
- Does continuity need the same characters, the same event type, or either? Continuity does not necessarily need all of these factors. But it's nice to see character continuity, for instance (I'd say this is the most probable to detect as continuity).
- How should a connection that spans two sessions (s1 → s3) be marked? Perhaps every connection should be marked with the original session it comes from and the final session (e.g., s1->s2, s1->s3, s2->s3).

## How the gold should use it

For each reference line (dialogue from earlier sessions), list the current-session events that continue it, and give each match one kind from the table. This lets later analysis separate "the RC finds continuity" from "the RC finds *interesting* continuity".
